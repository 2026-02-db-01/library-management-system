# 책담 홈페이지 디자인 결정

- 기준: `feature/frontend-v2`의 `d4a00391`. UI/UX Pro Max의 공공 서비스 추천에서 명확한 주요 행동, 고대비, 키보드 포커스, 충분한 터치 영역과 동작 감소 지원을 채택했다. 추천의 영문 전용 서체 대신 기존 한국어 서체 스택을 사용한다.
- 정보 구조: 서비스 소개·도서 검색과 로그인 → 주요 서비스 → 이용 안내. DB 관계도와 카탈로그는 기존 관리자 DB Console에 유지한다.
- Astryx 0.7.16의 `Theme`와 neutral 테마를 사용한다. 검색·로그인 및 역할 선택 컨트롤은 기존 프로젝트 UI와 스타일을 사용한다.
- 홈페이지 토큰: 텍스트 `#17243b`, 보조 텍스트 `#526174`, 네이비 `#172e50`, 테두리 `#dce3ea`; 최대 콘텐츠 폭 1160px, 모바일 좌우 20px, 본문 14–16px, 주요 버튼 최소 높이 48px.
- 회원 목업 역할에서는 검색어와 검색 유형을 `/user/books`에 전달한다. 그 외에는 로그인 화면으로 목적지와 검색 조건을 전달한다. 고정 테스트 계정은 Mock Store의 역할별 화면으로 연결되며, 실제 인증이 아니다.

## 내부 페이지 확대 시 후속 작업

1. 기존 비계층 CSS와 Tailwind preflight, Astryx 레이어의 우선순위를 정리하고 컴포넌트별 시각 회귀를 확인한다.
2. 회원 검색·대출, 사서 업무, 관리자 표·폼에서 접근성 및 키보드 조작을 검증하면서 버튼과 입력 컴포넌트를 단계적으로 교체한다.
3. 모달, 데이터 표, 상태 메시지와 DB Console의 토큰·반응형 표현을 통일하고 기존 업무 테스트를 유지한다.
4. 실제 인증과 서버가 도입될 때 데모 역할 전환 표시와 사용자 동선을 별도로 재설계한다.
