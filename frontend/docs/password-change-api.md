# 본인 비밀번호 변경 API

FR-03, BR-26, BR-51을 지원한다. 활성 상태의 회원·사서·관리자는 로그인한 본인의 비밀번호를 변경할 수 있다.

- `POST /api/v1/auth/change-password`는 `currentPassword`(1~128자)와 `newPassword`(12~128자)를 받는다. 새 비밀번호는 현재 비밀번호와 달라야 한다. 확인 값은 브라우저에서 비교한다.
- 서버는 기존 해시(Argon2 또는 bcrypt)로 현재 비밀번호를 검증하고, 새 비밀번호는 Argon2로 해시하여 저장한다. 성공하면 `204 No Content`를 반환한다.
- 현재 비밀번호가 틀리면 `400 CURRENT_PASSWORD_MISMATCH`, 현재 비밀번호를 그대로 쓰면 `422 PASSWORD_UNCHANGED`, 필드 규격을 위반하면 `422`를 반환한다. 만료·무효 세션은 `401`, 비활성 계정은 `403`으로 처리한다.
- 변경 성공 후 현재 브라우저의 쿠키를 제거한다. 변경 전 발급한 해당 계정의 토큰도 다음 인증 요청부터 `401`로 거부한다. 다른 계정에는 영향을 주지 않는다.
- 이 기능이 배포되기 전에 발급된 토큰에는 새 인증 정보가 없어 다시 로그인해야 한다. 이후 발급된 토큰에 계정별 세션 검증을 적용한다.
- 내 계정의 비밀번호 변경 폼은 처리 중 중복 제출을 막고, 성공 후 로그인 화면으로 이동한다. 비밀번호와 확인 값은 브라우저 저장소에 저장하지 않는다.
