# 프론트엔드 목업 및 실제 서비스 전환 현황

기준: 로컬 `feature/home-astryx`, Wiki 요구사항 문서 및 V2 Mock 구현. 기존 Astryx 변경을 포함한 미커밋 상태에서 작업했다.

## 현재 확인된 사실

- 실제 인증 서버 및 API 계약은 이 저장소의 `backend`에 구현되어 있지 않다. 로그인과 회원가입은 입력을 검증하지만 서버 미연결 오류를 반환하며 성공을 표시하지 않는다. 인증 전송 인터페이스는 제안이며 엔드포인트나 세션 방식은 확정되지 않았다.
- 실제 세션 확인, 로그인 완료, 역할별 인증 가드, 로그아웃 및 비밀번호 변경은 **미구현**이다. 서버의 인증·권한 검증과 쿠키/CSRF 정책을 확정하고 통합해야 한다.
- 현재 개발 목표는 프론트엔드 목업이다. 회원·사서·관리자 업무 화면과 DB Console은 브라우저 Mock Store를 사용하며 실제 운영에 사용할 수 없다. 실제 서비스 전환 시 화면별 데이터 공급 계층 및 인증 적용이 필요하다.
- ERD와 정적 12테이블 메타데이터, 관계 및 기존 데이터 탐색 UI는 유지했다. DB Console의 레코드는 아직 실제 DB 응답이 아니다. 인증 서버와 권한 검증이 준비되기 전 원시 데이터 조회를 운영에 노출해서는 안 된다.
- 기존 Mock은 FR-01~16, FR-18~20, FR-22~23의 일부 업무 흐름을 제공하지만 실제 서버 기능 구현이나 모든 BR의 검증을 의미하지 않는다. FR-17 인증과 FR-21 네트워크 중복 방지는 미구현이다.
- NFR-01~08, 10, 14~20의 서버·DB 보장은 미구현 또는 통합 검증 대기다. NFR-09, 11~13은 일부 클라이언트 검증과 자동 테스트만 확인했으며 전체 시스템 요구사항 통과를 의미하지 않는다.
- 분류 코드, 최초 관리자 및 직원 초기 인증, 탈퇴 ID 재사용, 날짜·시각 정정, 요청 기록 보존과 장애 복구 정책은 결정 대기다.

## 이번 작업

- `/login`, `/signup` 입력 검증 및 서버 미연결 UI, 인증 인터페이스와 실패 처리, 단위·브라우저 테스트를 추가했다. 비밀번호는 폼 상태에서만 다룬다.
- 홈페이지는 Astryx 테마, 도서 검색, 로그인 폼과 역할별 목업 바로가기를 제공한다. 실제 로그인과 회원가입 요청은 서버 미연결 상태이며, 기존 합성 회원가입은 별도 목업 경로에서 제공한다.

## 다음 단계

서버 인증·세션·오류 계약과 접근 권한을 확정한 뒤 API 상태 관리와 화면별 데이터 공급원을 교체하고, 대체 기능의 검증이 끝난 후 Mock 역할·데이터·초기화 UI를 제거한다. 실제 DB의 트랜잭션, 동시성, 권한과 비식별화는 통합 환경에서 검증해야 한다.
